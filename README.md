# auto-giga-recruiter

CLI-утилита, которая входит в твой Telegram-аккаунт, открывает бота **ГигаРекрутер**, выбирает вакансию и проходит ИИ-интервью за тебя. Ответы генерирует **Claude** на основе твоих резюме из папки `resumes/`.

```
╭───────────────────────────────────────────╮
│            auto-giga-recruiter            │
│ ИИ-интервью в ГигаРекрутере на автопилоте │
╰───────────────────────────────────────────╯
╭ 🤖 ГигаРекрутер ─────────────────────────────╮
│ Расскажите о самом сложном проекте.          │
╰──────────────────────────────────────────────╯
                 ╭──────────────── 🧑 Я · 412/800 симв. ╮
                 │ В прошлом году я переводил платёжный │
                 │ монолит на микросервисы…             │
                 ╰──────────────────────────────────────╯
```

## Как это работает

- **Telegram:** по умолчанию утилита управляет **Telegram Web** в невидимом браузере ([Playwright](https://playwright.dev)): открывает чат с ботом, читает сообщения, нажимает кнопки и печатает ответы. Вход по QR-коду прямо в терминале, `api_id`/`api_hash` не нужны. Есть альтернативный драйвер `mtproto` на [GramJS](https://github.com/gram-js/gramjs), если ключи с my.telegram.org у тебя есть.
- **ИИ:** по умолчанию — **твоя подписка Claude** через установленный [Claude Code](https://claude.com/claude-code) (`claude -p`): ключ API не нужен. Если в `.env` задан `ANTHROPIC_API_KEY`, используется [Anthropic API](https://github.com/anthropics/anthropic-sdk-typescript) с оплатой по токенам. На каждом шаге Claude получает новые сообщения бота и список кнопок, а возвращает структурированное действие: `reply` (ответить текстом), `click` (нажать кнопку), `wait` (ждать дальше) или `finish` (интервью окончено).
- **Выбор резюме:** резюме подбирается под вакансию само, по названию и описанию. Ключевые слова берутся из имени файла: `resume.vue.md` выбирается, если в вакансии упоминаются Vue, Nuxt, Pinia; `resume.react.md`, если React, Next.js, Redux. Если стек не понятен, берётся `resumes.default`, а без него резюме с `react` в имени.
- **Живой текст:** ответы пишутся как набранные человеком на клавиатуре. Длинные тире, ёлочки, символ многоточия, стрелки заменяются на обычные символы; если в ответе оказался иероглиф или эмодзи, ответ уходит модели на переделку.
- **Резюме:** резюме лежит в системном промпте и кэшируется (prompt caching), поэтому каждый следующий ход стоит дешевле.
- **Лимит символов:** модели передаётся лимит; если ответ длиннее, она дважды получает просьбу сократить его; если и это не помогло, текст обрезается по границе предложения.
- **Имитация человека:** перед отправкой показывается статус «печатает…», задержка пропорциональна длине ответа. Прежде чем отвечать, утилита ждёт, пока бот допишет серию сообщений.

## Установка

Нужен Node.js 20+.

```bash
npm install
npm run setup              # скачает Chromium для Playwright (~150 МБ, один раз)
npm start -- init          # создаст config.yaml и .env из примеров
```

1. Убедись, что Claude Code установлен и в нём выполнен вход по подписке: команда `claude` в терминале открывается без запроса логина (иначе `/login`). Ключ API не нужен. Если хочешь платить по токенам вместо подписки, впиши `ANTHROPIC_API_KEY` в `.env`.
2. Положи резюме в `resumes/` (`.md` или `.txt`). Образец: `resumes/example.md`.
3. Проверь `bot.username` и `answers.maxChars` в `config.yaml`.

```bash
npm run login              # в терминале появится QR-код: Telegram на телефоне → Настройки → Устройства → Подключить устройство
                           # если включена двухэтапная проверка — спросит облачный пароль
npm start -- status        # проверка: конфиг, резюме, ключ, бот найден
```

Если браузер не запускается в WSL/Linux из-за системных библиотек, выполни `sudo npx playwright install-deps chromium`.

## Использование

```bash
# 1. Разведка: посмотреть, как устроен бот (сообщения, кнопки, callback data)
npm run recon                        # отправит /start и будет слушать
npm run recon -- --interactive       # сам нажимаешь кнопки и отвечаешь из CLI
#    Дамп сохраняется в data/recon/*.json, HTML чата — в data/recon/*.html
#    (если Telegram поменял вёрстку, по нему правятся telegram.web.selectors в config.yaml)

# 2. Репетиция без Telegram: вопросы интервьюера вводишь ты, отвечает ИИ
npm run interview -- --dry-run
#    Кнопки задаются так: «Готовы начать? || Да | Нет»

# 3. Боевой режим
npm run interview                          # вакансию выбираешь из списка кнопок; после интервью снова меню
npm run interview -- --all                 # пройти все доступные интервью подряд (то же: пункт меню «🚀»)
npm run interview -- --vacancy "Java"      # вакансия выбирается сама (подстрока или индекс кнопки)
npm run interview -- --confirm             # каждый ответ одобряешь, правишь или перегенерируешь
npm run interview -- --resume backend.md   # явно указать резюме (по умолчанию выбирается по стеку вакансии)
npm run interview -- --no-start            # продолжить с текущего места чата, без /start

npm run help                               # все команды и их опции (npm run help -- interview — одна команда)
npm run resumes                            # список резюме и их размер в токенах
npm run logout                             # удалить сессию с диска
```

У `login`, `recon` и `interview` есть флаг `--headful`: он показывает окно браузера, чтобы видеть, что происходит. В WSL для этого нужен WSLg (есть в Windows 11).

`Ctrl+C` один раз останавливает интервью и сохраняет транскрипт, второй раз завершает процесс сразу.

## Конфиг

Все параметры с комментариями — в [`config.example.yaml`](config.example.yaml). Основные:

| Параметр | Что делает |
|---|---|
| `telegram.driver` | `web` (по умолчанию, браузер) или `mtproto` (нужны `TG_API_ID`/`TG_API_HASH`) |
| `answers.maxChars` | жёсткий лимит символов в одном ответе |
| `answers.honesty` | `strict`: только факты из резюме, без выдуманного опыта |
| `answers.extraInstructions` | чего нет в резюме: зарплата, формат работы, срок выхода |
| `behavior.mode` | `auto` (по умолчанию) или `confirm` |
| `behavior.typingDelay` | диапазон задержки «печатает…» |
| `behavior.questionTimeoutSec` | если у бота есть таймер на ответ, задержки подстроятся под него |
| `resumes.perVacancy` | правило «регулярка по названию вакансии → файл резюме» |
| `llm.provider` | `auto` / `claude-code` (подписка) / `api` (ключ) |
| `llm.model` / `llm.effort` | модель Claude и глубина рассуждений |

## Безопасность

Репозиторий публичный, поэтому все личные данные держатся **вне git**:

| Что | Где | В git? |
|---|---|---|
| `ANTHROPIC_API_KEY`, если используешь API (и для mtproto `TG_API_ID`, `TG_API_HASH`, `SESSION_PASSPHRASE`) | `.env` | ❌ |
| Сессия Telegram Web (даёт **полный доступ к аккаунту**) | профиль браузера `data/browser-profile/`, права 700 | ❌ |
| Сессия mtproto | `data/session.enc`, права 600, AES-256-GCM при заданном пароле | ❌ |
| Резюме | `resumes/*` (кроме `example.md`) | ❌ |
| Транскрипты интервью, дампы recon | `data/` | ❌ |
| Личный конфиг | `config.yaml` | ❌ |
| Телефон, пароль 2FA | нигде, вводятся интерактивно | — |

Дополнительно:
- **Pre-commit хук** (`scripts/guard-staged.mjs`) не даёт закоммитить `.env`, `config.yaml`, `data/`, файлы сессий и личные резюме, а также прогоняет [secretlint](https://github.com/secretlint/secretlint) по индексу. Хук ставится автоматически при `npm install`; вручную: `npx simple-git-hooks`.
- Логи и транскрипты проходят через redaction: ключи, api hash, телефон и строка сессии заменяются на `***`.
- Проверить весь репозиторий: `npm run secretlint`. Для надёжности можно дополнительно прогнать [gitleaks](https://github.com/gitleaks/gitleaks): `gitleaks detect`.
- Профиль браузера не шифруется: не копируй папку `data/` и не отдавай её никому.
- Если сессия могла утечь, выполни `npm run logout` и заверши сеанс «Telegram Web» в приложении: *Настройки → Устройства*.

## Риски и ответственность

- Telegram может ограничить аккаунт за автоматизацию. Браузерный режим выглядит как обычный Telegram Web, но задержки всё равно включены по умолчанию; не убирай их.
- Если Telegram обновит вёрстку веб-версии, браузерный режим может перестать видеть сообщения или кнопки. Тогда запусти `npm run recon` и поправь селекторы в `config.yaml` по сохранённому HTML (или пришли его мне).
- Правила ГигаРекрутера и работодателя могут запрещать прохождение интервью ассистентом. Решение и ответственность за использование — на тебе.
- ИИ может ошибаться. При `honesty: strict` модель не придумывает опыт, но перед важными интервью прогони `--dry-run` и `--confirm`.

## Разработка

```bash
npm run typecheck
npm test
npm run build              # сборка в dist/ (tsup)
```

Структура: `src/telegram/web/` — браузерный драйвер (вход по QR, чтение чата, селекторы); `src/telegram/` — общий интерфейс чата и драйвер mtproto; `src/llm/` — Claude, промпты и схема действий; `src/interview/` — навигация, цикл интервью и recon; `src/ui/` — отрисовка в терминале.
